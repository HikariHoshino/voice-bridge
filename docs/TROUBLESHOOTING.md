# 使用与排障

## 手机打不开配对页面

- 确认手机和电脑连接同一个可信 Wi-Fi。
- Windows 防火墙只允许声桥访问“专用网络”。
- 关闭可能改变路由的 VPN 后重试。
- 声桥每 3 秒检测当前有默认网关的局域网地址，并自动重新绑定变化后的 IP。出现 `ERR_ADDRESS_UNREACHABLE` 时，先确认手机和电脑在同一 Wi-Fi，再按电脑端更新后的二维码重新打开；跨网络后旧数值 IP 无法继续使用。
- 不要把 `8765` 端口映射到互联网。

## 显示“配对链接无效”

电脑端执行过“重新配对”后，旧收藏和旧二维码会立即失效。重新扫描当前二维码即可。

## 点击发送但电脑没有文字

- 发送前先点击电脑目标输入框，确认光标正在闪烁。
- 确认电脑端没有暂停接收。
- 普通权限运行的声桥通常不能向管理员权限窗口注入文字。
- 密码框、终端安全模式和部分禁止粘贴的软件可能拒绝输入。
- 如果发送失败，可以在手机端点击撤销，恢复发送前被清空的文字。

## 发送后电脑剪贴板发生变化

这是当前稳定输入路径的预期行为。为保证长文本瞬时发送并严格保留格式，声桥把原始 Unicode 文本放入 Windows 剪贴板并发送一次 `Ctrl+V`；发送后剪贴板保留刚发送的文本。

## 换行、空格或 Markdown 异常

声桥不会主动整理文本格式。若结果不同：

1. 先在 Windows 记事本中测试同一段文字。
2. 确认目标应用自身没有自动编号、自动缩进或 Markdown 格式化功能。
3. 不要在传输过程中使用会自动改写剪贴板的第三方工具。

## 电脑发给手机没有出现

- 保持手机声桥页面处于打开状态。
- 页面恢复后会继续轮询，电脑端只保留最近 50 条未持久化消息。
- 电脑端退出会清空待发送队列。
- 文字只会进入声桥网页，不能直接进入其他手机 App。

## 端口被占用或启动失败

默认端口为 `8765`。关闭其他声桥实例或占用该端口的软件后重新启动。正常情况下，第二次启动声桥只会唤醒已有窗口，不会创建新服务进程。

## 窗口关闭后找不到程序

如果关闭行为设置为“最小化到托盘”，声桥仍在通知区域运行。点击托盘图标可重新打开，或通过托盘菜单彻底退出。

## 配置恢复

配置文件位于：

```text
%LOCALAPPDATA%\VoiceBridge\config.json
```

删除该文件会重置设置、累计字符数和配对令牌。删除前应先退出声桥；再次启动后需要重新扫码。
