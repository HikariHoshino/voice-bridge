# 声桥

一个供个人使用的 Windows 双向文字桥：手机可以把语音输入的文字送到电脑当前光标，电脑也可以把文字送到声桥手机页面的当前光标。

## 核心能力

- 手机无需安装 App，浏览器打开配对页面即可使用任意手机语音输入法。
- 手机文字直接发送到 Windows 当前光标，完整保留换行、空格、制表符、Markdown 和 Unicode。
- 电脑文字可发送到手机声桥页面的当前光标。
- 手机可以远程按下电脑回车，并按设置启用二级确认。
- 配对链接、界面设置和累计字符数保存在电脑端，多次启动后继续有效。
- 支持单实例、系统托盘、开机自启、深浅色主题和高 DPI 显示。

## 使用

1. 确保手机和电脑连接同一个 Wi-Fi。
2. 打开打包目录，运行 `VoiceBridge\VoiceBridge.exe`；请保留旁边的 `_internal` 文件夹。
3. 如果 Windows 防火墙询问，只允许“专用网络”。
4. 首次使用时，手机扫描窗口中的二维码，然后收藏该页面或添加到主屏幕。
5. 在手机页面点击输入框，再点击手机输入法的麦克风说话。
6. 将电脑光标放到目标输入框，然后在手机点击“发送到电脑”。
7. 电脑发给手机时，在电脑窗口下方输入文字并点击“发送到手机页面光标”。

电脑端二维码默认隐藏，点击“显示二维码”会打开独立配对窗口，再次点击或关闭配对窗口即可隐藏。“设置”中可以选择开机自启、关闭窗口行为、电脑端发送快捷键，以及是否显示累计输入字符数。累计字符数会跨启动保留，也可以在设置中清零。

手机页面提供“发送到电脑”和“按下回车”两个主按钮。回车按钮需要连续确认两次，第一次会变色显示“确认吗？”，第二次才会在电脑当前光标处按下回车。清空、撤销、复制位于下方三个圆形副按钮中。页面外观可选择跟随系统、浅色或深色。

手机端手动点击“清空”或成功“发送到电脑”后都可以点击“撤销”，恢复清空前的文字和光标位置。这个撤销只发生在手机页面，不会撤回已经输入到电脑的内容；输入新文字后撤销记录会失效。

默认点击窗口关闭按钮时，会询问“最小化到托盘”还是“直接关闭”。也可以在设置中固定一种行为；托盘菜单可以重新打开声桥或彻底退出。

配对密钥和首次选定的局域网 IP 会保存在当前 Windows 用户的 `%LOCALAPPDATA%\VoiceBridge\config.json` 中。普通重启、打开二维码或从托盘恢复窗口都不会重新选择 IP；只有在配对窗口中点击“刷新地址”才会检测当前网络、重新绑定并保存新 IP。若换到其他网络后旧 IP 已不可用，程序会保留旧值并提示手动刷新，不会在后台偷偷改址。点击“重新配对”只会主动更换密钥，不会刷新 IP；这两种操作都会使原收藏链接失效，需要重新扫码。

声桥只允许一个实例运行。窗口已最小化到托盘时，再次启动会恢复现有窗口；若后台占用实例来自不兼容的旧版本，程序会明确提示先从托盘彻底退出。未处理异常记录在 `%LOCALAPPDATA%\VoiceBridge\crash.log`，便于区分真实崩溃与后台实例拦截。

## 当前边界

- 仅支持 Windows。
- 手机和电脑需要在同一局域网。
- 手机发送到电脑的文字统一通过剪贴板快速粘贴；发送后，电脑剪贴板会保留刚发送的文字。
- 手机网页受系统沙箱限制，电脑不能直接向其他手机 App 的光标输入；可以先接收到声桥页面，再点击“复制”粘贴到其他 App。
- 某些管理员窗口、密码框或禁止粘贴的软件可能无法自动输入。
- 电脑发给手机但手机页面尚未打开时，最多暂存最近 50 条文字；关闭电脑端后清空。

## 网络安全

详细风险和使用建议见 [SECURITY.md](SECURITY.md)。个人使用时至少做到：只连接可信的私人 Wi-Fi、不在路由器上开放 `8765` 端口、不需要接收时点击“暂停手机输入电脑”，配对链接泄露后点击“重新配对”。

## 从源码运行

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python app.py
```

## 重新打包

```powershell
python -m PyInstaller --noconfirm --clean VoiceBridge.spec
```

最终采用文件夹便携版，而不是单文件模式：这样运行时只有一个声桥进程，启动也更快。整个 `VoiceBridge` 文件夹可以一起复制到其他位置使用。
